1. 什么是变量？

在 Python 中，变量不需要预先声明类型。你可以把它看作是一个贴着标签的盒子。当你写下 age = 25 时，你就是把 25 这个值放进了名叫 age 的盒子里。

python
# 定义一个整数变量
age = 25

# 定义一个字符串变量
name = "Alice"

# 打印它们
print(f"{name} is {age} years old.")

2. 核心数据类型

  • 整数 (int): 例如 1, 100, -5
  • 浮点数 (float): 例如 3.14, -0.001
  • 字符串 (str): 用单引号、双引号括起来的文本，如 "Hello"
  • 布尔值 (bool): 只有 True 和 False

💡 提示: 可以使用 type() 函数随时查看变量的数据类型。Python 是动态类型语言，同一个变量可以先后指向不同类型的值。
