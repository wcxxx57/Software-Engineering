# Iteration 4：资源推荐前端布局

## 设计约束

- 复用现有暖米色画布、棕金文字、蓝色 K2V、紫色 C2V、绿色可操控 2D，以及现有 `rounded-2xl`、`rounded-3xl`、半透明卡片和柔和阴影。
- 不新增独立推荐页面，不修改全局字体、色系或导航结构。
- 不展示“高质量视频”“人工精选”等来源标签；内容是否可推荐由后端保证，前端只说明它为什么适合当前用户。
- 所有学习者数据必须是匿名聚合数据，不能显示用户身份或私人信息。

## 1. 有课程大纲的知识点任务页

只有任务已绑定课程大纲中的固定知识点时，显示三类独立的个性化推荐区块。每一类资源独立换一条、独立生成，互不影响。

### 推荐理由文案

按实际数据选择一至两条，不拼接未经验证的理由：

- `与你当前学习进度相近的学习者通常先通过动画建立概念理解`
- `内容聚焦你正在学习的查找、插入与删除过程`
- `适合巩固你在小测中尚未掌握的内容`
- `已有 {count} 位学习者学习过`
- `与你学习基础相近的学习者完成率较高`

无候选资源时，隐藏推荐内容和理由，只保留当前资源类型自己的生成入口。

## 2. 独立 K2V / C2V / 2D 页面

从主页直接进入的工具页不读取当前计划、知识点或用户画像。页面只展示后续上传的可展示资源，保持现有工具页生成台、播放器和历史列表结构。

```text
┌─ Knowledge 2 Video ──────────────────────────────────────────────────┐
│ 推荐内容                                                               │
│ [封面] 二叉搜索树：从概念到操作                      [立即观看]       │
│ [封面] 递归思维入门                                  [立即观看]       │
│                                                                         │
│ ───────────── 现有在线生成台 / 播放器 / 生成历史 ─────────────        │
└─────────────────────────────────────────────────────────────────────────┘
```

K2V 使用蓝色系、C2V 使用紫色系、可操控 2D 使用绿色系；卡片圆角、按钮、阴影均复用现有 `ContentCard` 与工具页样式。

## 3. 知识点页右栏：AI 伴学与问题推荐

复用现有任务页右侧 `AI 伴学` 侧栏；不新开 Chat 页面，也不改变任务页的主栏与侧栏比例。顶部始终展示当前课程、阶段和知识点，确保用户知道提问范围。

```text
┌─ AI 伴学 ─────────────────────────────┐
│ Python 基础 / 树结构                    │
│ 当前知识点：二叉搜索树                   │
│                                        │
│ ┌─ 猜你想问 ─────────────────────────┐ │
│ │ 二叉搜索树和普通二叉树有什么区别？ │ │
│ │ 为什么查找效率与树的高度有关？      │ │
│ └────────────────────────────────────┘ │
│                                        │
│ ┌─ 用户常问 ─────────────────────────┐ │
│ │ 删除有两个子节点的节点时怎么办？    │ │
│ │ 8 位学习者问过                       │ │
│ │ 为什么二叉搜索树会退化成链表？      │ │
│ │ 12 位学习者问过                      │ │
│ └────────────────────────────────────┘ │
│                                        │
│ AI：你可以围绕当前知识点向我提问。      │
│ 我：删除有两个子节点时怎么办？           │
│                                        │
│ [输入你的问题……                    ][发送]│
└────────────────────────────────────────┘
```

- “猜你想问”使用现有暖黄/橙色聊天表面色，问题以可点击圆角条目呈现；点击后写入输入框并发送。
- “用户常问”使用中性白色半透明卡片与棕色文字，问题来自当前知识点的真实匿名聚合记录；不展示用户身份、原始聊天记录或私人信息。
- 没有达到展示阈值的真实问题时，完整隐藏“用户常问”区块，不能用 AI 生成问题补位。
- 两类问题的接口、标题和视觉容器必须独立，避免用户把个性化建议误认为真实高频问题。

## 4. 学习计划推荐

在主控台的学习计划区域补充“推荐计划”卡片：用户可在创建计划前查看推荐计划，也可继续自行创建。该卡片使用现有计划卡片的白色半透明底、棕金标题和圆角样式，不采用资源类型色。

```text
┌─ 为你推荐的学习计划 ─────────────────────────────────────────────────┐
│ 数据结构与算法基础                                                     │
│ 4 个阶段 · 16 个学习任务 · 预计 3 周                                   │
│                                                                         │
│ 推荐给你：与你当前的学习目标和 Python 基础学习进度相衔接。              │
│                                                                         │
│ [预览计划]                                      [采用此计划]           │
│                                      [我想自己制定计划]                 │
└─────────────────────────────────────────────────────────────────────────┘
```

- 推荐理由只基于后端实际返回的学习目标、课前测、学习时间、掌握情况或已有计划完成情况。
- “预览计划”在现有页面中打开对话框/抽屉，展示阶段、任务和预计学习节奏；关闭预览不创建计划。
- “采用此计划”需要二次确认后创建计划；“我想自己制定计划”进入现有自定义计划流程。
- 没有合适模板时不展示空推荐卡，保留原有创建计划入口。

## 5. 当前计划完成后的下一计划推荐

在现有任务完成卡片返回“计划已完成”后，原地展示下一阶段建议；不额外跳转页面。

```text
┌─ 恭喜完成：Python 基础学习计划 ───────────────────────────────────────┐
│ 下一步建议：数据结构与算法基础                                         │
│                                                                         │
│ 推荐给你：它与你的学习目标相衔接，并以前置的 Python 基础为起点。        │
│ 4 个阶段 · 16 个学习任务 · 预计 3 周                                   │
│                                                                         │
│ [预览下一计划]                    [采用下一计划] [继续自定义]          │
└─────────────────────────────────────────────────────────────────────────┘
```

- 仅在当前学习计划全部完成时出现；不实现学习过程中的动态调期、提前推进或自动重排。
- “采用下一计划”必须由用户确认，不自动切换当前计划。
- 推荐无结果时仍保留完成奖励与返回主控台操作，不显示虚构的下一计划。

## 6. 接口边界

- 知识点页推荐接口按 `taskId + resourceKind` 返回当前知识点匹配的候选及真实推荐理由。
- 独立工具页接口只返回可展示资源；不返回或展示用户画像理由。
- AI Chat 仍位于任务页右栏，自动接收课程、阶段与知识点上下文；“用户常问”和“猜你想问”保持数据来源隔离。
- 推荐计划接口返回计划摘要、真实推荐理由及预览所需的阶段和任务；接受操作需显式确认。
- 当前计划完成后，现有完成卡片显示下一计划预览与采用操作。
